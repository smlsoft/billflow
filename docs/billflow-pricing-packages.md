### เงื่อนไขทดลองใช้งาน

- ใช้กับ 1 บริษัท SML / 1 ฐานข้อมูล SML
- ใช้งานมาตรฐานของ BillFlow ก่อน
- ทีม BillFlow ช่วยตั้งค่าเริ่มต้นให้
- หากระบบไม่ช่วยลดงานคีย์ได้จริง ลูกค้าสามารถหยุดหลังจบช่วงทดลอง โดยไม่มีค่ารายเดือนต่อเนื่อง
- งานเฉพาะร้าน เช่น รายงานเฉพาะ, กฎเฉพาะ, onsite training หรือเชื่อมต่อระบบอื่นนอกเหนือจาก SML คิดเพิ่มตามขอบเขตงาน

## วิธีทำงานของ BillFlow

BillFlow ไม่ได้มาแทน SML แต่ช่วยลดงานคีย์ซ้ำจาก Shopee, Lazada, TikTok, อีเมล และ LINE OA แล้วส่งข้อมูลเข้า SML ได้เร็วขึ้น

1. นำไฟล์หรืออีเมลเข้าระบบ
2. ตรวจรายการที่ต้องแก้ก่อนส่งเข้า SML
3. จับคู่ชื่อสินค้าจากต้นทางกับรหัสสินค้า SML
4. ส่งเข้า SML เฉพาะรายการที่พร้อม
5. ดูประวัติย้อนหลังได้ว่าใครส่ง เมื่อไร SML ตอบอะไร และถ้าส่งไม่สำเร็จเกิดจากอะไร

## ข้อควรสื่อสารกับลูกค้า

- BillFlow ไม่ส่งเข้า SML อัตโนมัติทันทีทุกกรณี ต้องตรวจก่อนส่งเพื่อลดความเสี่ยงข้อมูลผิด
- Lazada และ TikTok เริ่มจากไฟล์ Excel/CSV ก่อน ยังไม่ใช่การเชื่อมต่ออัตโนมัติเต็มรูปแบบ
- มูลค่าหลักไม่ใช่แค่อ่านบิล แต่คือการลดงานคีย์, จับคู่สินค้า, ส่งเข้า SML และตรวจย้อนหลังได้
- ลูกค้าควรเริ่มจากงานที่มีบิลเยอะที่สุดก่อน แล้วค่อยเพิ่มช่องทางหรืองานฝั่งซื้อภายหลัง

## Fair Usage

BillFlow ไม่จำกัดจำนวนบิลแบบ hard limit เพื่อให้ลูกค้าไม่ต้องกังวลว่าบิลเยอะแล้วค่าใช้จ่ายจะพุ่งทันที

หากมีปริมาณการใช้งานสูงผิดปกติจนกระทบ performance, ค่า AI, storage หรือ server resource ทีมงานจะคุยกับลูกค้าเพื่อปรับแพ็กเกจหรือแยก instance ให้เหมาะสม

ตัวอย่างกรณีที่อาจต้องปรับแพ็กเกจ:

- มีหลายบริษัท SML หรือหลายฐานข้อมูล SML
- มีหลายสาขาและต้องแยกงาน
- มีบิลจำนวนมากผิดปกติเมื่อเทียบกับร้านทั่วไป
- ต้องการกฎเฉพาะร้านหรือรายงานเฉพาะทาง
- ต้องการ SLA หรือเวลาตอบสนองเฉพาะ

## ข้อความหน้าเว็บหลัก

ลดงานคีย์บิลจาก Shopee เข้า SML เริ่มจาก Shopee วันนี้ เพิ่ม Lazada/TikTok ได้ภายหลัง โดยค่าเริ่มต้น 4,900 บาทครั้งเดียว และเริ่ม 1,290 บาท/เดือน

BillFlow ช่วยให้พนักงานตรวจเฉพาะรายการที่ต้องแก้ เช่น สินค้าไม่ตรง หน่วยไม่ตรง ราคาไม่ครบ หรือข้อมูลจากต้นทางไม่ชัดเจน แทนการคีย์ทุกบิลใหม่ด้วยมือ
