## ความต้องการโดยย่อ

บริษัทต้องการเช่าเซิร์ฟเวอร์ Cloud **1 เครื่อง** เพื่อรันซอฟต์แวร์บริหารจัดการใบสั่งซื้อ (BillFlow) สำหรับทีมงานภายในบริษัท 5–20 คน

ซอฟต์แวร์นี้ทำงานตลอด 24 ชั่วโมง เพื่อรับและประมวลผลใบสั่งซื้อจาก Email อัตโนมัติ

**ผู้ดูแลระบบ:** ทีม BillFlow (ดูแลการติดตั้งและ configuration ให้ทั้งหมด ลูกค้าไม่ต้องดำเนินการด้านเทคนิคใดๆ)

## Spec เซิร์ฟเวอร์ที่ต้องการ

| รายการ | ความต้องการ |
|---|---|
| CPU | **2 vCPU** |
| RAM | **4 GB** |
| พื้นที่เก็บข้อมูล | **60 GB SSD** |
| ปริมาณ Internet | **500 GB/เดือน ขึ้นไป** (หรือไม่จำกัด) |
| ระบบปฏิบัติการ | **Ubuntu Linux 22.04 หรือ 24.04** (64-bit) |
| ที่ตั้ง Datacenter | **ประเทศไทย** |
| IP Address | **Static IP 1 หมายเลข** (IP ถาวร ไม่เปลี่ยน) |
| สิทธิ์การเข้าถึง | **Root access** (ทีมดูแลระบบต้องการเพื่อติดตั้งโปรแกรม) |
| จำนวนเครื่อง | **1 VM** |

## ซอฟต์แวร์ที่รันบนเซิร์ฟเวอร์

ซอฟต์แวร์ทั้งหมดติดตั้งผ่าน **Docker** (ทีมดูแลระบบติดตั้งให้เอง ไม่ต้องการให้ผู้ให้บริการติดตั้ง)

| โปรแกรม | หน้าที่ | หน่วยความจำที่ใช้ |
|---|---|---|
| ระบบ API หลัก (Go) | ประมวลผลคำสั่ง, เชื่อม AI, รับ Email | ~80 MB |
| หน้าเว็บ (React) | แสดงผลสำหรับผู้ใช้งาน | ~8 MB |
| ฐานข้อมูล (PostgreSQL) | เก็บข้อมูลบิล, ลูกค้า, ประวัติ | ~155 MB |
| ระบบปฏิบัติการ + Docker | พื้นฐานการทำงาน | ~300 MB |
| **รวมทั้งหมด** | | **~540 MB จาก 4,000 MB** |

**การใช้พื้นที่เก็บข้อมูล:**

| รายการ | ปัจจุบัน | คาดการณ์ 1 ปี |
|---|---|---|
| โปรแกรม (Docker images) | ~3 GB | ~3 GB |
| ฐานข้อมูล | ~0.2 GB | ~1 GB |
| ไฟล์ PDF / เอกสาร | ~0.5 GB | ~3 GB |
| Backup รายวัน | ~1.2 GB | ~3 GB |
| ระบบปฏิบัติการ + logs | ~5 GB | ~8 GB |
| **รวม** | **~10 GB** | **~18 GB** |

## คำถามที่ต้องการคำตอบ

กรุณาตอบคำถามต่อไปนี้พร้อมใบเสนอราคา:

1. **ราคา** — รายเดือนและรายปีเท่าไหร่? มีส่วนลดถ้าทำสัญญายาวไหม?
2. **ค่า VAT** — ราคาข้างต้นรวม VAT 7% แล้วหรือยัง?
3. **Backup / สำรองข้อมูล** — มีบริการสำรองข้อมูลอัตโนมัติไหม? ราคาเท่าไหร่? เก็บย้อนหลังได้กี่วัน?
4. **Static IP** — รวมในแพ็กเกจหรือคิดค่าใช้จ่ายเพิ่ม?
5. **SLA รับประกัน** — ระบบทำงานได้กี่เปอร์เซ็นต์? ถ้าล่มเกินกำหนดมีนโยบายคืนเงินไหม?
6. **ช่องทาง Support** — ติดต่อได้กี่โมง? ทาง Chat / โทรศัพท์ / Ticket? ตอบภายในกี่นาที/ชั่วโมง?
7. **ช่วย migrate ข้อมูล** — ช่วยย้ายข้อมูลจากเซิร์ฟเวอร์เดิมให้ได้ไหม? มีค่าใช้จ่ายไหม?
8. **ชำระเงิน** — รับบัตรเครดิต / โอนเงิน / PromptPay ไหม?
9. **ขยาย spec ภายหลัง** — ถ้าต้องการเพิ่ม RAM หรือ CPU ทำได้ทันทีไหม? ระบบต้องหยุดทำงานนานแค่ไหน?
10. **ทดลองก่อน** — มี trial period หรือ refund policy ไหม?
